# Recollect template chooser

Select the template matching the user-facing recollection depth chosen at intake:

- `RECOLLECT-QUICK.md` — compact briefing for fast memory reset and editorial triage.
- `RECOLLECT-FULL.md` — richer working notes for later article preparation.

Do not fill this chooser as an output template. Record the selected depth, generation date or run identifier, and transcript basis in the chosen artifact. Switching depth reuses the transcript but generates a new mode-specific notes file.
